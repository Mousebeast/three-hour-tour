# Mods pinned in pack/manifest.json that are deliberately absent from the
# dedicated server's mods/ directory. The manifest is the client-and-server
# pack definition (what the CurseForge client imports); the server install
# is a subset of it. A mod belongs here when it is genuinely client-only —
# it stays in the manifest for players, it is just never staged to
# /srv/minecraft/3ht/mods.
#
# Format: <fileName as staged by tools/download-mods.sh> | <reason>

sodium-neoforge-0.8.12+mc1.21.1.jar | Client-only rendering mod. Crashes the dedicated server outright: NeoForge's early-window bootstrap (ImmediateWindowHandler) invokes every ImmediateWindowProvider SPI found in mods/ unconditionally, before client/server side-filtering happens. Sodium's PreLaunchChecks then does Class.forName("org.lwjgl.Version"), which isn't on the dedicated server classpath (no LWJGL/GLFW there), producing NoClassDefFoundError and an immediate exit before any mod-loading log lines. First hit at Task 5 boot attempt 1. See docs/mod-audit.md.
iris-neoforge-1.8.14-beta.1+mc1.21.1.jar | Client-only shader mod. Its own neoforge.mods.toml declares side="CLIENT" for its minecraft and embeddium dependencies, and it provides no server-side function (shader rendering only). Does not crash the server (no ImmediateWindowProvider SPI, unlike Sodium) — excluded on hygiene/policy grounds, not a boot failure.

Better-Leaves-9.5.zip | Client resource pack, not a mod. Pinned in the manifest so the CurseForge client installs it for players; a .zip in a dedicated server's mods/ is never loaded and only obscures what is actually installed. Added to this list 2026-08-21 after tools/download-mods.sh was found staging it.
ComplementaryUnbound_r5.8.1.zip | Client shader pack (requires Iris, itself excluded above). Same reasoning as Better-Leaves — no server-side function.
dynamiclights-v1.9.3-mc1.17-26.2.9-datapack.zip | Client-side dynamic lighting datapack. Ships to players via the manifest. If a server-side datapack is ever wanted it belongs under config/paxi/datapacks/ (see pack/README.md), never mods/.
