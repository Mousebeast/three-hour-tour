# 3ht — mod list of record

**Hand-maintained, despite what this file used to claim** (corrected
2026-09-02). It said it was generated by `tools/build-manifest.py`; that
script *reads* a modlist, and nothing writes this file. So the counts below
are a derivation from a date, not a live figure, and they had gone stale.

against what is staged in both directions and is the only figure worth
quoting. As of 2026-09-02 that is 253 jars staged, 0 unattributed, 0 missing.
