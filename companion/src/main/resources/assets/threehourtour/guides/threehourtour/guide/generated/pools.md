# Trophy pools

Every boss drops a trophy, and every trophy crafts one-for-one into a **seal**. Research asks for seals — never for a named boss.

Any boss in a pool will do. A node asking for a seal never cares which of that pool's bosses you managed to kill.


## Alpha — <ItemLink id="threehourtour:seal_alpha" />

- **Wither** of Overworld — a Named Gate pearl
- **Ignis** — a Named Gate pearl
- **Netherite Monstrosity** — a Named Gate pearl

## Beta — <ItemLink id="threehourtour:seal_beta" />

- **Dead King** of The Mage Covenant — a Named Gate pearl
- **Maledictus** — a Named Gate pearl
- **Harbinger** — a Named Gate pearl

## Delta — <ItemLink id="threehourtour:seal_delta" />

- **Echo of Tyros** of The Mage Covenant — a Named Gate pearl
- **Ender Dragon** of The Ender Guardian — a Named Gate pearl
- **Scylla** — no gate; it is already in the ocean

## Gamma — <ItemLink id="threehourtour:seal_gamma" />
