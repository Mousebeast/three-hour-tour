# The Nether and the End

**Both are shut.** Step into a portal and you will be turned back with a message
saying so. You can build the portal. You can light it. You can stand in it and
think about your choices. You are not going through.

Everything either dimension would have given you is somewhere else in this
pack. Nothing is missing; it has all just moved to a worse neighbourhood.

## What replaces what

| What you would have gone for | Where it comes from now |
|---|---|
| Netherrack, soul sand, basalt and friends | the cobblestone generator's own tiers |
| Nether wart | Ignis, through its gates or its data model |
| Blaze rods | Ignis, through its data model |
| Ancient debris | the Netherite Monstrosity, and a vein |
| Gold in bulk | the Ancient Remnant, and the nether gold vein |
| Quartz, glowstone | veins, in the overworld |
| End stone | the Ender Guardian |
| Ender pearls | the Overworld gate, which anyone can open on day one |
| The Ender Dragon | a Named Gate, fought in an arena like every other boss |

See **Gates and bosses** for how those arenas work, and **Metal and ore veins**
for the veins.

## The one that is not a swap

**Heat.** Create's own heat tier runs on Blaze Burners, which need netherrack to
build and a live blaze to light — both behind the door. So they are not in this
pack: Create Propulsion's Solid and Liquid Burners do the job instead, and
they need copper sheets and a blast furnace rather than a trip.

If you have played Create before, this is the one habit you will have to break.
