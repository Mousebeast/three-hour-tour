# Shortcut recipes

Several research packs have a second way to fill a bundle. Every one of them
follows a single rule:

> **You built infrastructure, so this is cheaper.**

A shortcut is a discount on the *gathering*. It never removes the activity the
pack exists to make you do, and it never changes the last step — a pack is still
finished by its own signature however its bulk was made.

## What each one rewards

| Pack | Shortcut | What you had to build |
|---|---|---|
| Trawl | Trading Hall | a villager hall, or depth-gated treasure crates |
| Trawl | Kiln | a furnace — which means you have made landfall |
| Foundry | Mechanical Crafting | Mechanical Crafters |
| Arcane | Printing | the Enchantment Industry printer |
| Abyssal | Brushed Artefacts | a lit outpost over an ocean ruin |

Each pack's page shows its shortcuts with the exact counts, and what they save
against the base recipe.

**Farm has no shortcut**, and is not getting one. Crops come out of passive
planters without anybody doing anything, and a discount for owning a planter is
a discount for going to bed.

## Arcane's is not a way around the fighting

Arcane's printing path still carries the same fourteen Gateway Ash the base
recipe does. It is cheaper — forty-nine items against sixty-three — but there is
no version of an Arcane pack that does not represent an arena somebody cleared.
